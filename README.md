# sdg4-learning-system
Software Engineering project for SDG 4 – Quality Education. Learning Management System prototype.

SDG 4 – Integrated Learning Management System

Sustainable Development Goal
This project supports SDG 4: Quality Education.

Project Overview
The Integrated Learning Management System is designed to bring together academic tools such as timetable viewing, assignment submission, grade tracking, and announcements for students and lecturers.

Problem Statement
Students often use multiple platforms for academic management, which leads to confusion and missed deadlines.

Solution
A unified mobile based platform that integrates important academic functions into a single system.

SDLC Approach
This project follows Agile methodology using Scrum practices. Trello is used for task management and sprint tracking, while GitHub is used for version control and documentation.
